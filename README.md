# 🌿 ระบบจัดการลานยางพาราชุมชน (Rubber Yard App)

เว็บแอพสำหรับจัดการลานรับซื้อยางพาราชุมชน รองรับระบบล็อกอิน สมาชิก คำนวณน้ำหนักหลายเที่ยว และคำนวณราคา

## ✨ ฟีเจอร์หลัก

- 🔐 ระบบล็อกอินแอดมิน
- 📊 แดชบอร์ดสรุปยอดวันนี้ / เดือนนี้
- 👥 จัดการสมาชิก (รหัสตัวเลข, ชื่อ, เบอร์โทร, เลขบัญชี)
- ⚖️ รับซื้อยาง — รองรับชั่งหลายเที่ยว หักรถเข็นทุกเที่ยว
- 📋 ประวัติธุรกรรม + กรองตามวันที่/สมาชิก
- 🧾 พิมพ์ใบเสร็จ
- ⚙️ ตั้งค่าราคายาง, เปอร์เซ็นต์หัก, รหัสผ่าน

## 🛠️ เทคโนโลยี

- HTML / CSS / JavaScript (ไม่ใช้ framework)
- [Supabase](https://supabase.com) — ฐานข้อมูล PostgreSQL ออนไลน์

## 🚀 วิธีใช้งาน

1. สมัคร [Supabase](https://supabase.com) แล้วสร้างโปรเจค
2. รัน SQL สร้างตารางในระบบ
3. แก้ไข `SUPABASE_URL` และ `SUPABASE_KEY` ใน `app.js`
4. Deploy ขึ้น Vercel หรือ Netlify
